# flowmusic 🎵

Spotify-like music player with Yandex Music integration built with Electron and React.

## Features

- ✅ Yandex Music OAuth authentication
- ✅ Browse playlists (Premiere, DejaVu, etc.)
- ✅ Play tracks with full metadata
- ✅ Spotify-like UI
- ✅ Play/Pause/Next/Previous controls
- ✅ Volume control
- ✅ Progress bar with seeking

## Tech Stack

- Electron
- React
- Axios
- Electron Store
- Yandex Music API

## Installation

```bash
# Clone repository
git clone https://github.com/yourusername/flowmusic.git
cd flowmusic

# Install dependencies
npm install

# Build the app
npm run build

# Start the app
npm start
